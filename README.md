# Lista de exercícios em C

Sou Lucas Marcondes Delfino e organizei aqui minhas soluções dos 56 exercícios de Algoritmos e Pensamento Computacional, da Universidade Positivo.

Cada exercício está em um arquivo separado, de `ex01.c` a `ex56.c`, na pasta [Lista_Exercicios_Lucas_Marcondes_Delfino](Lista_Exercicios_Lucas_Marcondes_Delfino).

Para compilar um arquivo com GCC, por exemplo:

```bash
gcc -std=c11 Lista_Exercicios_Lucas_Marcondes_Delfino/ex01.c -o ex01 -lm
./ex01
```
